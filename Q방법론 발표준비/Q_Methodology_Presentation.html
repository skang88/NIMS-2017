  • 거친 텍스트 결과물(`.lis`)을 다시 엑셀로 수동 정리해야 하는 극심한 노가다

2세대 방식의 한계 진단

왜 'RStudio + 웹 AI 코드 생성'도 초심자에게는 어려운가?

웹 챗봇은 내 PC의 파일을 볼 수 없기 때문에, 결국 사람이 코드를 수정(디버깅)해야만 한다!

장벽 구분 웹 AI가 만들어준 코드의 문제점 RStudio 실행 시 터지는 에러 초심자가 직접 해야 했던 일 (고통)
① 파일 경로(Path)
지정 오류		 read.csv("C:/your/path/data.csv")처럼 가상의 경로로 코드를 짜줌 Error: cannot open file
(No such file or directory)		 내 PC 폴더 경로를 찾아 복사하고, 역슬래시(\)를 슬래시(/)로 직접 코드에서 수정해야 함
② 데이터 변수명
상상 코딩 문제		 내 파일 안의 실제 열 이름을 모르니 data$score, df$id처럼 임의로 코딩함 Error: $ operator is invalid
또는 NULL / Subscript Error		 엑셀/JSON 파일을 열어 실제 변수명(scoresArray 등)을 찾아 코드의 변수값을 일일이 고쳐야 함
③ 패키지 충돌 및
한글 인코딩 깨짐		 패키지가 이미 깔려 있다고 가정하거나 윈도우/맥 한글 인코딩 차이를 무시함 there is no package 'qmethod'
/ 한글 열 이름 깨짐 에러		 에러 메시지를 다시 복사해 챗봇에게 물어보고 UTF-8 / CP949 옵션을 수동 수정해야 함

3세대 핵심 해법 · 역할 위임

해결책: Claude Code · Codex · Antigravity에게 역할을 부여하라!

PC에 R만 설치되어 있으면 RStudio를 켤 필요조차 없다 — 에이전트가 파일 읽기부터 실행까지 전담

에이전트가 내 PC 폴더 안의 엑셀, CSV, JSON 파일을 직접 열어서 행/열 구조, 실제 변수명, 응답자 수를 스스로 파악합니다.

ROLE 02 · 맞춤 코딩

방금 스스로 읽은 실제 파일 경로와 정확한 변수명을 그대로 넣어, 사람이 수정할 필요가 없는 R 스크립트를 생성합니다.

ROLE 03 · 자율 실행
R 직접 실행 & 자가 치유

에이전트가 백그라운드에서 PC의 R을 직접 구동합니다. 패키지 미설치나 에러가 나면 스스로 원인을 읽고 고쳐서 재실행합니다.

ROLE 04 · 결과 산출
산출물 & 리포트 완성

요인적재치, Z-점수, 구별 진술문 CSV 파일과 질적 인터뷰가 결합된 논문용 분석 보고서를 폴더에 자동 저장합니다.

사전 준비물 (딱 2가지만 설치!)

1) PC에 R 기본 프로그램 설치: cran.r-project.org에서 설치 (RStudio는 몰라도 됨)
2) 로컬 AI 에이전트 설치: Claude Code, OpenAI Codex, Google Antigravity 중 택 1

연구자가 얻는 해방감

• 에이전트에게 많은 역할(파일 읽기 + 검증 + 실행 + 정리)을 부여할수록 연구는 쉬워집니다.

실전 노하우 STEP 1 · 데이터 입력

데이터 입력부터 쉽게! — 소팅 데이터를 파일로 준비하는 2가지 노하우

과거 PQMethod처럼 띄어쓰기 칸수를 맞출 필요가 없다! 엑셀이든 웹 JSON이든 폴더에 넣기만 하면 끝

방식 A. 오프라인 카드 소팅 ➔ 엑셀(CSV) 입력

현장에서 종이 카드로 소팅을 진행했을 때 가장 편한 방법:

  • 자유로운 표 입력: 첫 열에 진술문 번호(Q01~Q36), 옆 열에 응답자 이름(P01, P02...)을 적고 피라미드 점수(-4 ~ +4)만 입력!
  • 행·열 방향 무관: 사람과 문항의 행/열을 반대로 적었어도 OK! 에이전트가 읽으면서 알아서 전치(Transpose) 처리함.
  • 💡 오타 검증 꿀팁 (합계 = 0 법칙): 좌우 대칭 피라미드(-4~+4)는 한 응답자의 점수 합계가 무조건 0이어야 함! 에이전트에게 "합계가 0이 안 되는 오타 응답자가 있는지 먼저 검사해 줘"라고 시키면 1초 만에 색출!
방식 B. 온라인 웹 Q-소팅 앱 ➔ JSON 자동 수집

비대면 조사 또는 수동 입력 자체를 없애고 싶을 때 (실습 방식):

  • 드래그 앤 드롭 소팅: 단일 HTML 웹 앱을 응답자에게 전달해 화면에서 피라미드 배치 후 결과 파일(.json) 다운로드.
  • 입력 오타 확률 0%: 피라미드 칸수 정원(-4는 2칸, 0은 8칸 등)이 맞지 않으면 완료 버튼이 눌리지 않아 결측치·오타가 원천 차단됨!
  • 점수 + 인터뷰 통합 저장: 배치 점수(scoresArray)와 양 극단(+4, -4) 선택 이유 텍스트가 파일 하나에 묶여서 생성됨 ➔ data/ 폴더에 모아 넣기만 하면 입력 완료!
폴더 정리 노하우: 내 PC 바탕화면에 프로젝트 폴더를 하나 만들고, 그 안에 data 폴더를 만들어 응답 파일들과 36개 진술문 텍스트 파일을 함께 넣어두면 준비 끝입니다!
실전 노하우 STEP 2 · 분석 실행

에이전트에게 어떻게 지시(Prompt)하면 알아서 읽고 실행할까?

내가 변수명을 알려주지 말고, "네가 먼저 파일을 열어서 구조를 파악하고 R을 실행해라"라고 지시한다!

💬 Claude Code / Codex / Antigravity에 그대로 복사해서 입력하는 [실전 만능 지시문]
"내 PC의 현재 폴더 안(data/ 폴더)에 Q-방법론 소팅 응답 파일들과 36개 진술문 목록이 들어있어.
나는 RStudio나 코딩을 모르니, 네가 직접 아래 4가지 역할을 순서대로 수행해 줘:

1. [파일 직접 읽기]: 먼저 data/ 폴더 안의 파일들을 네가 직접 열어서 변수명과 데이터 구조(점수 배열, 응답자 정보, 인터뷰 텍스트 등)를 스스로 파악해.
2. [무결성 검수]: 응답자별로 36개 점수가 강제분포 척도(-4~+4: 2,3,4,5,8,5,4,3,2칸)에 맞게 입력되었는지 먼저 검증해.
3. [R 직접 실행]: 내 PC에 설치된 R(qmethod, psych 패키지 활용, 없으면 네가 직접 설치)을 실행해서 주성분분석(PCA)과 배리맥스(Varimax) 회전을 수행해.
4. [산출물 저장]: output/ 폴더를 만들어 ① 상관행렬, ② 요인적재치 및 자동 플래깅(p<0.01) 표, ③ 요인별 Z-점수 및 Q-배열표, ④ 합의·구별 진술문 표, ⑤ 질적 인터뷰 정리표를 엑셀에서 바로 열 수 있는 CSV로 저장해 줘."
1. 에이전트의 자율 탐색

에이전트가 스스로 샘플 파일을 열어 scoresArray, respondent$id 같은 내부 변수명을 정확히 읽어냅니다.

2. 백그라운드 R 구동

run_nims_q_analysis.R 스크립트를 자동 생성하고 터미널에서 R을 직접 돌려 5초 만에 계산을 끝냅니다.

3. 에러 발생 시 자가 수정

패키지가 없거나 경로 문제가 생기면 에이전트가 스스로 코드를 수정해 성공할 때까지 완수합니다.

실전 노하우 STEP 3 · 산출 및 해석

데이터 산출부터 해석까지 — 어떤 표가 나오고 논문에 어떻게 쓰는가?

output/ 폴더에 자동 생성되는 5대 핵심 산출물 읽는 법과 질적 인터뷰 결합 노하우

산출 파일명 (output/) 담겨 있는 핵심 통계 데이터 논문 제4장 작성 시 핵심 확인 포인트 (해석 노하우)
① Factor_Loadings.csv 응답자별 요인적재치 및 자동 플래깅(flag=TRUE) ★ 최우선 확인! TRUE가 표시된 응답자가 각 유형(Factor)을 대표하는 인물임 (누가 어느 유형에 속했는지 분류)
② Factor_Zscores.csv 36개 진술문의 요인별 Z-점수 및 Q-배열 점수(-4~+4) 각 유형이 가장 강하게 동의(+4, +3: Z점수 상위)하는 문항과 가장 거부(-4, -3: Z점수 하위)하는 문항으로 유형의 철학 파악
③ Consensus_Distinguishing.csv 유형 간 Z-점수 차이 유의성 검정 (p < 0.05) • 합의 진술문: 모든 유형이 공통으로 동의하는 보편적 기반
• 구별 진술문: 유형 간 관점이 극명하게 갈리는 핵심 쟁점!
④ Qualitative_Interviews.csv 응답자별 양 극단(+4, -4) 선택 이유 서술문 통계 수치(Z-점수)가 왜 그렇게 나왔는지 응답자의 생생한 육성 인용문("...")으로 논문의 질적 타당성 입증
최고급 실전 노하우: 에이전트에게 '통계 수치 + 진술문 텍스트 + 인터뷰 이유' 1:1 매칭 시키기!

원래는 연구자가 엑셀 파일 3개를 띄워놓고 "Q08번의 Z점수가 몇 점이고, Q08번 문장 내용이 뭐였으며, 1유형 응답자가 왜 Q08번을 골랐는지" 눈으로 찾으며 복사·붙여넣기를 해야 했습니다.
➔ 에이전트에게 "방금 뽑은 CSV 파일들과 진술문 원문, 인터뷰 이유를 하나로 결합해서 유형별 분석 표와 리포트(HTML/MD)로 정리해 줘. 단, 원 데이터에 없는 수치나 내용은 절대 지어내지 마!"라고 지시하면 수 시간의 대조 작업이 단 1분 만에 끝납니다!
